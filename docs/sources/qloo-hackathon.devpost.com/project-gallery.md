## Method

The gallery at the 2026-10-16 crawl listed 343 projects on 15 pages, with the 4 winners first. Each project got one primary theme, judged from its gallery title and tagline only; project pages, demos, and Qloo usage were not checked, so placements are judgment calls. Projects that span themes went to the one their tagline leads with, for example a travel planner built on cross-domain taste goes under travel.
