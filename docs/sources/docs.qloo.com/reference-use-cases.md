# Key Use Cases

Explore the various ways you can use the Insights API based on your desired input and output. Below you'll find detailed guides for a few of the most common use cases:

- [Recommendation Insights](https://docs.qloo.com/reference/basic-insights-use-case): Retrieve recommendations based on the entity type.
  - [Location-Based Insights](https://docs.qloo.com/reference/insights-with-location-use-case): Retrieve recommendations based on location.
- [Demographic Insights](https://docs.qloo.com/reference/demographics-use-case): Retrieve the demographic affinity scores for an entity or tag.
- [Heatmaps](https://docs.qloo.com/reference/heatmaps-use-case): Generate heatmap data.
- [Taste Analysis](https://docs.qloo.com/reference/taste-analysis): Retrieve tag metadata.
